# Tidepool

**Public URL:** Pending deployment. See [README.md](README.md) for the Render setup steps.

**Description (130 words):**

Tidepool is a quick multiplayer strategy game about finding a quiet corner in a changing sea. Two to six explorers meet in a room shared by a five-letter code or invite link, then make a choice at the same time each round: which of five little reefs will they visit? A reef is worth more when fewer people land there, but each player also has a private favorite reef that earns a bonus. One public tide shifts the value of the map each turn, so players balance comfort against crowding. Six short rounds decide who read the water best. Newcomers can jump into solo practice with two computer explorers, while groups get a ready-up lobby, reconnectable seats, and a rematch in the same room. No accounts or downloads are needed.
